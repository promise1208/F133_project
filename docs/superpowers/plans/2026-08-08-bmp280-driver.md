# BMP280 I2C Driver Implementation Plan

> `For agentic workers:` REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a custom BMP280 I2C kernel module for the F133 board's PE0/PE1 `twi1` bus, expose compensated temperature and pressure through sysfs, and verify the module on the target board.

**Architecture:** Keep the driver out of the kernel tree under `project/driver/bmp280/`. A small shared math header contains the Bosch fixed-point compensation routines and can be tested with the host compiler. The kernel module owns I2C transactions, calibration storage, forced measurements, locking, and sysfs attributes. The device tree binds the module through the private `dawn,bmp280` compatible at address `0x76`.

**Tech Stack:** Linux 5.4 kernel module APIs, `i2c_driver`, SMBus byte/block helpers, device tree, sysfs, C11 host test, the existing RISC-V cross-toolchain and `ubuntu18_04` build container.

- [ ] **Step 3: Add the minimal shared compensation implementation.**

Create `bmp280_math.h`. Use kernel integer types when included from the module and standard fixed-width types in the host test. Keep pressure in Q24.8 until the caller rounds it to Pa.

```c
#ifndef DAWN_BMP280_MATH_H
#define DAWN_BMP280_MATH_H

#ifdef __KERNEL__
#include <linux/types.h>
#else
#include <stdbool.h>
#include <stdint.h>
typedef uint16_t u16;
typedef int16_t s16;
typedef int32_t s32;
typedef int64_t s64;
typedef uint32_t u32;
#endif

struct dawn_bmp280_calib {
	u16 dig_t1;
	s16 dig_t2;
	s16 dig_t3;
	u16 dig_p1;
	s16 dig_p2;
	s16 dig_p3;
	s16 dig_p4;
	s16 dig_p5;
	s16 dig_p6;
	s16 dig_p7;
	s16 dig_p8;
	s16 dig_p9;
};

static inline s32 dawn_bmp280_compensate_temp(
	const struct dawn_bmp280_calib *calib, s32 adc_temp, s32 *t_fine)
{
	s32 var1;
	s32 var2;

	var1 = (((adc_temp >> 3) - ((s32)calib->dig_t1 << 1)) *
		(s32)calib->dig_t2) >> 11;
	var2 = (((((adc_temp >> 4) - (s32)calib->dig_t1) *
		  ((adc_temp >> 4) - (s32)calib->dig_t1)) >> 12) *
		(s32)calib->dig_t3) >> 14;
	*t_fine = var1 + var2;

	return (*t_fine * 5 + 128) >> 8;
}

static inline bool dawn_bmp280_compensate_press(
	const struct dawn_bmp280_calib *calib, s32 adc_press, s32 t_fine,
	u32 *pressure_q24_8)
{
	s64 var1;
	s64 var2;
	s64 pressure;

	var1 = (s64)t_fine - 128000;
	var2 = var1 * var1 * (s64)calib->dig_p6;
	var2 += (var1 * (s64)calib->dig_p5) << 17;
	var2 += ((s64)calib->dig_p4) << 35;
	var1 = ((var1 * var1 * (s64)calib->dig_p3) >> 8) +
		((var1 * (s64)calib->dig_p2) << 12);
	var1 = ((((s64)1 << 47) + var1) * (s64)calib->dig_p1) >> 33;
	if (!var1)
		return false;

	pressure = (((((s64)1048576 - adc_press) << 31) - var2) * 3125) /
		var1;
	var1 = ((s64)calib->dig_p9 * (pressure >> 13) *
		 (pressure >> 13)) >> 25;
	var2 = ((s64)calib->dig_p8 * pressure) >> 19;
	pressure = ((pressure + var1 + var2) >> 8) +
		((s64)calib->dig_p7 << 4);

	if (pressure < 0 || pressure > 0xffffffffLL)
		return false;
	*pressure_q24_8 = (u32)pressure;
	return true;
}

#endif
```

## Task 3: Implement the I2C Driver and Sysfs Interface

**Files:**
- Create: `project/driver/bmp280/dawn_bmp280.c`
- Modify: `project/driver/bmp280/Makefile` only if the object name changes during compilation; keep `obj-m := dawn_bmp280.o`.

- [ ] **Step 1: Add register definitions, driver state, and calibration decoding.**

The source must include `linux/i2c.h`, `linux/mutex.h`, `linux/of.h`, `linux/sysfs.h`, `linux/delay.h`, `linux/unaligned.h`, and the local `bmp280_math.h`. Use these register constants and state shape:

```c
#define DAWN_BMP280_REG_ID          0xd0
#define DAWN_BMP280_REG_CALIB       0x88
#define DAWN_BMP280_REG_CTRL_MEAS   0xf4
#define DAWN_BMP280_REG_STATUS      0xf3
#define DAWN_BMP280_REG_DATA        0xf7
#define DAWN_BMP280_CHIP_ID         0x58
#define DAWN_BMP280_CTRL_FORCED_X1  0x25
#define DAWN_BMP280_STATUS_MEASURING BIT(3)

struct dawn_bmp280_data {
	struct i2c_client *client;
	struct mutex lock;
	struct dawn_bmp280_calib calib;
	u8 chip_id;
};
```

Read exactly 24 bytes from `DAWN_BMP280_REG_CALIB` with `i2c_smbus_read_i2c_block_data`. Decode all fields with `get_unaligned_le16()` and cast the signed coefficients to `s16`. Treat a short read as `-EIO` and propagate negative I2C errors.

- [ ] **Step 2: Add forced measurement and compensation.**

Implement a measurement helper that is called while `data->lock` is held, with this contract:

```c
static int dawn_bmp280_measure(struct dawn_bmp280_data *data,
			       s32 *temperature_centi_c,
			       u32 *pressure_pa);
```

The helper must:

1. Write `0x25` to `0xf4` for temperature x1, pressure x1, forced mode.
2. Poll `0xf3` until bit 3 clears, sleeping with `usleep_range(1000, 2000)` between polls and failing with `-ETIMEDOUT` after 20 ms.
3. Read six bytes from `0xf7` and decode pressure from bytes 0-2 and temperature from bytes 3-5 as 20-bit unsigned values.
4. Call `dawn_bmp280_compensate_temp()` first so it produces `t_fine`.
5. Call `dawn_bmp280_compensate_press()`, convert Q24.8 to Pa with `(q24_8 + 128) / 256`, and return `-EIO` if the compensation helper rejects the result.

Do not retain stale values in the sysfs path. Every failed write, poll, read, or compensation step must return its error.

- [ ] **Step 3: Add sysfs attributes.**

Implement `chip_id_show`, `temperature_mdegc_show`, and `pressure_pa_show` with `scnprintf`. The temperature show function multiplies the centi-degree result by 10 to report milli-degrees Celsius. Each sensor attribute locks `data->lock`, invokes `dawn_bmp280_measure()`, unlocks on every path, and returns the error if measurement fails.

Register them in one attribute group:

```c
static DEVICE_ATTR_RO(chip_id);
static DEVICE_ATTR_RO(temperature_mdegc);
static DEVICE_ATTR_RO(pressure_pa);

static struct attribute *dawn_bmp280_attrs[] = {
	&dev_attr_chip_id.attr,
	&dev_attr_temperature_mdegc.attr,
	&dev_attr_pressure_pa.attr,
	NULL,
};

static const struct attribute_group dawn_bmp280_attr_group = {
	.attrs = dawn_bmp280_attrs,
};
```

Create the group after successful chip-ID and calibration validation. Remove it in the driver's `remove` callback.

- [ ] **Step 4: Add probe, remove, match tables, and module registration.**

Probe must check:

```c
if (!i2c_check_functionality(client->adapter,
		I2C_FUNC_SMBUS_BYTE_DATA | I2C_FUNC_SMBUS_I2C_BLOCK))
	return -EOPNOTSUPP;
```

Then allocate state with `devm_kzalloc`, initialize the mutex, read and validate register `0xd0 == 0x58`, read calibration, save the state with `i2c_set_clientdata`, and create the sysfs group. Match only the private device-tree compatible and a private I2C ID:

```c
static const struct of_device_id dawn_bmp280_of_match[] = {
	{ .compatible = "dawn,bmp280" },
	{ }
};
MODULE_DEVICE_TABLE(of, dawn_bmp280_of_match);

static const struct i2c_device_id dawn_bmp280_id[] = {
	{ "dawn_bmp280", 0 },
	{ }
};
MODULE_DEVICE_TABLE(i2c, dawn_bmp280_id);
```

Use `module_i2c_driver()` and declare GPL-2.0 licensing, the driver author, and a description. Log the detected address and chip ID with `dev_info()` only after the complete probe succeeds.
